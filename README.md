
# 🐍 Snake & Ladder Game

A beautiful, fully playable **Snake and Ladder** web app built with pure HTML, CSS & JavaScript. Perfect for learning or just having fun!

## 🎮 Play Online
Just open `index.html` in any browser — no installation required!

## 📜 Rules (Classic Indian Style)

- **Board**: 10×10 grid (numbers 1 to 100)
- **Start**: Both players begin at **0** (outside the board)
- **Turn**: Roll a 6-sided die and move forward
- **Ladders** = Climb up instantly
- **Snakes** = Slide down instantly
- **Win**: Be the first to reach **exactly 100**
- If your roll would take you **past 100**, you stay in place
- 2 players (hotseat on same device)

## ✨ Features
- Smooth animated tokens with bounce effect
- Real snake & ladder icons on board
- Dice roll animation
- Mobile-friendly & responsive
- Spacebar to roll dice
- Beautiful retro arcade design
- One single HTML file (easy to host)

## 🚀 How to Run
1. Download / clone this repo
2. Open `index.html` in Chrome / Firefox / Edge
3. Or enable **GitHub Pages** → instant free website!

## 🛠️ Tech Stack
- HTML5
- CSS3 Grid + Modern animations
- Vanilla JavaScript (no frameworks)
